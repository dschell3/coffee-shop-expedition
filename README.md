# The Coffee Shop Expedition

A small two-player game made for a MATH 101 group project at Sacramento State. Two players take turns walking a token across a city grid, one block North or East at a time. Whoever reaches the coffee shop wins.

**Play it here:** https://dschell3.github.io/coffee-shop-expedition/

It runs on a phone or a laptop and needs no install. The whole game is the single `index.html` file in this repo, so you can also download that file and open it directly.

## What's in it

- **Classic.** The game from the worksheet, on three board sizes.
- **Variations.** The same game with switches for long moves, a train track you can't cross, and chaos turns where you may step back.
- **Puzzles.** Three short one-player puzzles that show the math behind the game: counting routes, the corner rule, and the Catalan numbers.

This was built for a class presentation and for fun and will not be developed further.
